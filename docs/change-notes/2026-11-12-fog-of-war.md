# 2026-11-12 — PR #11: Trailseek Fog of War exploration

**Branch:** `feat/fog-of-war-exploration`. Base: `main` after PR #10 `5c72c8a`.

## What is implemented

- **Original Trailseek visual overlay**: a translucent fog layer with georeferenced circular clearings. Fog shows only when the user explicitly enables it in the shared map theme picker, and is off by default.
- **Explore + Solo Tracking map only**: Fog is drawn after the basemap and beneath destination pins, recorded route polylines, GPS location markers and interactive controls. Deliberately **not** applied to the Digital Rope live group map, where visibility of safety/status markers has priority.
- **Visited areas from already-accepted SmartTrace positions**: only `TrackRecorder.add()`-accepted positions while solo tracking is actively recording, with a maximum of 50 m reported horizontal accuracy, add revealed cells (~0.001° per side) to local history. No independent location stream, no extra Bluetooth/camera use, no background location service.
- **Local state with a cap**: Riverpod + existing `LocalStore` / SharedPreferences records only coarse grid IDs. Duplicate fixes write nothing. History is capped at 6,000 cells; older areas are dropped after the cap. Opt-out stops collection but keeps history until the user explicitly clears it.
- **User controls**: map-world picker adds an opt-in toggle, current explored-zone count and confirmed Clear History action. Existing Classic, Adventure RPG and Night Trek remain selectable.
- **Regression tests**: defaults disabled, duplicate/invalid/low-accuracy fixes ignored, persisted state, opt-out/reset, corrupt index recovery.

## Scope, user safety and open checks

- Fog of War is **gamification only**; it must never imply safe/verified walking paths, current wildlife/weather conditions, safe passage or GPS precision.
- Historic tracks are not automatically backfilled. This first increment only reveals during new solo recordings after the setting is enabled; no explicit geofences, achievements or synced exploration at this stage.
- Memory cap means the oldest areas can re-fog after 6,000 cells. Grid dimensions vary by latitude. Fog does not imply exact path coverage.
- No Digital Rope SOS UI or BLE logic, navigation directions, background position providers or trail accuracy logic was changed.
- **Required before merge:** Flutter analysis + unit/widget tests, Android debug APK and iOS unsigned compilation. Device QA for zoom/rotation/fast pan, low-power recording, large history, reset, solo tracking pause/stop, and foreground/background behavior remains mandatory before production rollout.
